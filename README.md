# Syntecxhub To-Do List Manager

A simple command-line To-Do List Manager developed using Python.

This project was created as part of the Syntecxhub Python Programming Internship Task 1.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks permanently using JSON
- Load saved tasks when the program starts
- Input validation and error handling
- Menu-driven command-line interface

## Technologies Used

- Python 3
- JSON
- File Handling
- Functions
- Exception Handling
